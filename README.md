# CreditWise Loan System

A loan approval analysis project using exploratory data analysis and supervised machine learning.

## Notebook

`credit_wise_project.ipynb` covers missing-value handling, exploratory data analysis, categorical encoding, correlation analysis, train/test splitting and feature scaling, model training and evaluation, and feature engineering. The notebook compares models and selects Naive Bayes based on precision.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- pandas, NumPy, seaborn, Matplotlib, and scikit-learn

Install the dependencies with:

```bash
pip install jupyter pandas numpy seaborn matplotlib scikit-learn
```

## Run

Keep `loan_approval_data.csv` beside the notebook locally, then open `credit_wise_project.ipynb` in Jupyter and run the cells.

## Dataset

The dataset is intentionally excluded from version control. Obtain the data separately and save it as `loan_approval_data.csv` beside the notebook before running the project.
